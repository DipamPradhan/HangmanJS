# 🏴‍☠️ One Piece Hangman Game

Welcome to **One Piece Hangman**, a classic word guessing game with a full **One Piece** twist, built using **HTML**, **CSS**, and **JavaScript**. Guess One Piece characters, Devil Fruits, islands, and pirate terms one letter at a time before the pirate is drawn!

## 🚀 Live Demo

[Click here to play the game](https://hangman.dipampradhan.com.np/)

---

## 🛠️ Tech Stack

- **HTML** – Structure of the webpage
- **CSS** – Styling and layout (Straw Hat theme, mobile responsive)
- **JavaScript** – Game logic and interactivity

---

## 🎮 How to Play

1. Click **Generate Word** to set sail and get a random One Piece word.
2. Guess the word by clicking the on-screen keyboard or typing letters.
3. Correct letters are revealed; wrong guesses draw part of the pirate.
4. Win by guessing all letters before the pirate is fully drawn!
5. Words with spaces (e.g. _Gomu Gomu no Mi_) are supported — letters shrink to fit on any screen size.
